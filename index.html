⚙️ Configurar Firebase

Para la sincronización en tiempo real, necesitas tu configuración de Firebase. Crear proyecto gratis →

¿Cómo obtener la configuración?
  1. Ve a console.firebase.google.com
  2. Crea un proyecto (o usa uno existente)
  3. Ve a Configuración del proyecto → Tus apps → Web
  4. Copia el objeto firebaseConfig
  5. En Realtime Database, habilita la base de datos en modo de prueba
